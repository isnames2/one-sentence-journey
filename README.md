# One Sentence, One Journey

A complete story about a journey, told in exactly one sentence.

`main.py` (Python 3.13, standard library only) writes the sentence to
`/output/entry.txt`. The run is deterministic: the same bytes every time.

The sentence:

> I left home at seventeen with a train ticket folded inside my shoe and a coat two sizes too big, rode three days to a city where nobody knew my name, and came back at forty to find my mother had pressed that same ticket, still uncreased, between the pages of her Bible.

Run it:

```sh
python3 main.py
```
